# ByteSMS - Smart Panel

**ByteSMS** is a powerful, web-based management panel designed for high-performance operations. It features a modern UI with dark mode, real-time network monitoring, user management, proxy integration (HTTP/SOCKS5), and a fully functional Bale messenger bot.

## Project Structure
- `app.py`: Main entry point.
- `data/`: Contains configuration and database files (`config.txt`, `users.txt`, `logs.txt`, `settings.json`).
- `templates/`: HTML files (`index.html`, `login.html`).
- `static/`: Static assets (favicon).
- `lib/`: Custom python modules (`Api.py`).
